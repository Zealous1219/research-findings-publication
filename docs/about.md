# 说明

本站用于发布可公开的研究记录与市场信息整理。每个栏目独立维护，不代表任何来源机构的观点。

## A 股收盘简报

收盘简报基于当日已结算的公开可验证数据与结构化市场数据生成。报告会明确保留数据完整性或降级提示；当关键数据不完整时，不应将分析占位内容替换为结论。

## 股票池盯盘看板

股票池盯盘看板按交易日发布静态收盘快照，用于整理股票池行情、板块表现与主力资金流向。页面会区分 Wind 官方指数口径与股票池统计口径；同一股票可能同时属于多个板块，页面标注的唯一股票数量按去重口径计算。看板不提供实时行情，也不代表对所列板块或股票的推荐。

## 使用边界

- 内容不构成投资建议、投资邀约或收益承诺。
- 历史市场表现不代表未来结果。
- 发布内容会经过公开性检查，不包含 API Key、本地路径、运行日志或内部配置。
