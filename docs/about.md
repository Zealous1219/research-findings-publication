# 方法、口径与使用边界

本站用于发布可公开的研究记录与市场信息整理。每个栏目独立维护，不代表任何来源机构的观点。

## A 股收盘简报

收盘简报基于当日已结算的公开可验证数据与结构化市场数据生成。报告会明确保留数据完整性或降级提示；当关键数据不完整时，不应将分析占位内容替换为结论。

简报保持 13 节结构与"数据来源与免责声明"章节。事实数据、派生指标与 Agent 判断在视觉上分层呈现：事实章节使用中性表格与靛蓝章节线；分析章节（盘面结论、主线轮动、明日关注）使用独立的解释区，保留证据、确认条件与失效条件。

## 股票池盯盘看板

股票池盯盘看板按交易日发布静态收盘快照，用于整理股票池行情、板块表现与主力资金流向。页面会区分 Wind 官方指数口径与股票池统计口径；同一股票可能同时属于多个板块，页面标注的唯一股票数量按去重口径计算。看板不提供实时行情，也不代表对所列板块或股票的推荐。

不同日期的看板可能使用不同的数据来源与 schema。历史页面保留各自的来源标注、字段集合与覆盖率说明，不强制归一。

## 来源到发布的研究记录链路

1. **来源**：Wind 与明确标注的历史来源。
2. **校验**：日期、覆盖率、完整性和降级状态。
3. **解释**：事实、派生指标、Agent 判断分层。
4. **发布**：修订号、生成时间和适用边界。

## 数据状态与历史 schema 原则

- 每份报告以生成时的数据状态为准，保留完整性或降级提示。
- 数据来源、指标代码和统计口径在页面头与相关表格就近标注。
- 历史页面保留原始差异，包括来源变化、字段集合和修正说明。
- 不为了视觉统一而删除历史来源、覆盖率或 schema 差异。

## 使用边界

- 内容不构成投资建议、投资邀约或收益承诺。
- 历史市场表现不代表未来结果。
- 发布内容会经过公开性检查，不包含 API Key、本地路径、运行日志或内部配置。
